Datos y sincronización

Esta app es 100% estática (GitHub Pages, sin backend). Los datos viven en tu navegador y se pueden sincronizar con una Hoja de Cálculo de Google mediante un Apps Script publicado como aplicación web.

Ver código de Apps Script (copiar en la hoja de cálculo)

En tu Hoja de Cálculo: Extensiones → Apps Script, pega este código, luego Implementar → Nueva implementación → Aplicación web, ejecutar como tú mismo y acceso Cualquier persona. Copia la URL /exec arriba.
